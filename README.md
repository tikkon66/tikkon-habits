Описание проекта:    
tikkon.habit — это многостраничный веб-сервис для трекинга привычек и задач. Система включает умное распределение приоритетов, годовой трекер прогресса и автоматическую оценку продуктивности дня и недели.
Проект построен как полноценное SPA-приложение с авторизацией, хранением данных в облаке и реактивной архитектурой.

Страницы приложения:    
Маршрут	Название	Описание    
/login	Вход	Авторизация и регистрация пользователя    
/focus	Фокус	Главный экран с текущей задачей и приоритетом    
/lists	Списки	Управление привычками и задачами    
/year	Год	Годовой трекер прогресса    
/profile	Профиль	Личный кабинет пользователя    

Логика приоритетов:    
Система задач разделена по уровню важности:    
Приоритет	Тип    
P1	Важные задачи (сегодняшние и просроченные)    
P2	Важные привычки    
P3	Обычные привычки    
P4	Неважные задачи    

Система оценки дня:    
Оценка:	Условие    
Звёздный день: Выполнены все задачи    
Хороший день: Выполнены важные задачи или часть задач    
Нет данных:	Ничего не выполнено    

Система оценки недели:    
Оценка:	Условие    
Звёздная неделя:	5 и более звёздных дней    
Обычная неделя:	3–4 звёздных дня        
Провальная неделя:	0 звёздных дней    

Технологии:    
Vue 3 (Composition API)   
Pinia (управление состоянием)   
Vue Router 4    
Firebase (Authentication + Firestore)    
Vite (сборка проекта)    

    
О проекте:
tikkon.habit — это система для повышения личной продуктивности через привычки, приоритеты и ежедневную аналитику прогресса. Приложение помогает пользователю фокусироваться на действительно важных задачах и отслеживать долгосрочный прогресс.
